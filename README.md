# AulasIoT
Este projeto apresenta um roteiro de aprendizagem prática e progressiva em Internet das Coisas (IoT) voltado para a Indústria 4.0, utilizando o microcontrolador ESP32 simulado na plataforma Wokwi. Ele propõe três soluções sistêmicas que abrangem desde a coleta básica de dados de sensores até a integração com nuvens.
